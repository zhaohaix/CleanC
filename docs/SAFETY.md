# 安全与功能边界

## 清理与统计

A 级真实清理永久删除缓存，默认启动只扫描。模拟清理不删除。新增文件不加入原扫描清单；变化或受保护文件跳过。路径保护和修改时间复核无法替代完整的句柄级文件身份校验，仍需继续验证检查与删除之间的并发变化。

B 级仅提供只读检查、影响说明和系统工具入口。文件大小不代表可删除大小。休眠、还原点、驱动、组件存储应通过 Windows 对应机制处理。

安装文件候选由用户逐项选择、确认后通过 Windows 回收站处理。EXE 不一定是安装程序。系统安装缓存、AppData、ProgramData、运行程序目录和开发环境不属于普通候选。Windows 回收站行为受文件系统、容量和策略影响；遇到系统额外确认时应核对内容，程序不会自动接受确认。

## 扫描范围

只读扫描跳过链接和离线文件，不将不可读目录视为已完整统计。逻辑大小可能因硬链接、稀疏文件和压缩而不同于实际磁盘占用。整盘扫描限时 120 秒，聊天目录和安装文件扫描也有各自上限。

## 聊天数据

随机目录名、账号目录和桥接生成编号不能直接视为真实联系人或群号。类型统计基于目录和扩展名推断。未知归属单独展示，不提供按群删除数据库。

只读连接仅访问用户选择的本机读取服务。连接组件自行安装、运行和授权。最近消息附件不代表完整历史；远程链接不计为已下载文件。不要自动下载附件来估算本地空间。

## 本地隐私

不要提交日志、扫描报告、聊天数据库、账号配置或访问令牌。问题报告和截图应先脱敏。凭据不写入 CleanC 日志，但本地日志仍可能含文件名及错误。

## 验证建议

在有快照或备份的测试环境验证真实删除。使用合成缓存和金丝雀文件检查受保护路径、路径变化、链接、占用、取消、权限拒绝和磁盘满等情况。先预览，再对小范围缓存执行并检查日志。

当前预览版不承诺完整系统兼容性、精确可释放容量或一键回滚。
