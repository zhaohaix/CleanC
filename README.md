# CleanC

Windows C 盘空间分析与用户缓存清理工具，使用 C#、.NET 8 和 WPF 开发。MIT 开源。

当前为开发预览版。支持只读扫描、清理预览和确认后的文件处理；聊天连接与单会话附件统计处于验证阶段。

## 功能

| 页面 | 当前能力 |
| --- | --- |
| 日常清理 A 级 | 用户临时文件、缩略图缓存、Edge / Chrome 默认配置缓存；独立模拟清理与执行清理按钮 |
| 需确认处理 B 级 | 文件大小扫描、影响说明；未取得占用与官方工具入口单独展示 |
| 微信 / QQ 空间明细 | 按账号目录和文件类型统计，展示未识别会话附件目录及最大 100 个文件 |
| C 盘空间与安装文件 | 大目录、大文件定位；下载目录和桌面的安装文件候选由用户勾选处理 |
| 聊天只读连接 | 复用本机 SnowLuma / WeChatAgent 读取接口，核对联系人、群标识及选定 QQ 会话的附件 |

## 环境与启动

- Windows 10 / Windows 11，x64。
- 构建需要 .NET 8 SDK；运行框架依赖版需要 .NET 8 Desktop Runtime。
- 主程序不默认请求管理员权限；受保护目录可能无法完整扫描。

    dotnet build CleanC.sln -c Release
    dotnet run --project src/CleanC.App/CleanC.App.csproj -c Release

首次启动自动执行 A 级只读扫描。“模拟清理”生成计划与本地日志；“执行清理”需要二次确认。

## 文件处理范围

A 级只处理内置规则允许的缓存，真实清理使用永久删除。仅处理扫描清单内且大小和修改时间未变化的文件；浏览器缓存会重新检查浏览器进程。单次上限 5 GB / 20,000 个文件，超限中止。路径校验拒绝个人目录、系统目录、链接及开发环境等受保护位置。

B 级展示只读结果并引导至官方工具，不提供系统文件或聊天记录的一键删除。

安装文件候选仅来自 C 盘下载目录和桌面，默认不勾选。EXE 可能是程序本体，必须核对用途；桌面子目录中的 EXE 不列入候选。确认后使用 Windows 回收站界面，移入同盘回收站通常不会立刻释放磁盘空间。

完整说明见 [安全与功能边界](docs/SAFETY.md)。

## 大小统计限制

目录扫描统计文件逻辑大小，硬链接可能重复计算；不包含所有系统保留空间。达到扫描上限、权限不足或跳过链接时会显示限制。大小不等于可释放容量。

聊天明细根据文件扩展名和目录位置分类，不读取消息正文。目录标识不能可靠映射到群名或区分群聊和私聊；共享数据不会分摊到某个群。

## 聊天只读连接

第三方连接组件需要用户自行准备并运行，本仓库不分发微信、QQ、SnowLuma、WeChatAgent 或 Hook 组件。

- QQ：选择现有 SnowLuma 本机 HTTP 配置，读取登录身份、好友与群列表；用户选择会话后读取最近 100 条消息中的附件信息。
- 微信：选择现有 WeChatAgent 读取配置，读取联系人原始标识与显示名。
- 只允许本机 HTTP 地址，不自动启动机器人，不发送消息、不下载远程附件。
- 凭据仅用于本机连接，不写入项目日志。不要提交个人连接配置或数据库。
- 只有已核对存在的本地附件才计入本批大小；不代表该会话的完整占用。实时连接需要在对应组件版本与账号环境中验证。

## 测试

两个测试项目均为控制台测试程序，无第三方测试框架依赖：

    dotnet run --project tests/CleanC.Core.Tests -c Release
    dotnet run --project tests/CleanC.ChatStorage.Tests -c Release

覆盖路径保护、清理预览、扫描清单变化、浏览器状态、超限中止、文件分类、附件分组、路径去重、大文件排序、安装文件边界和目录统计。

文件操作测试会在临时目录创建并删除合成测试文件；环境限制写入或删除权限时可能失败。

## 发布便携版

    dotnet publish src/CleanC.App/CleanC.App.csproj -c Release -o artifacts/publish

复制整个发布目录，保留 EXE、DLL 和运行配置文件。不要仅复制 EXE。当前未提供签名安装包和自动更新。

## 隐私与贡献

缓存扫描与空间分析默认在本地执行。用户主动打开聊天连接或外部入口时会访问相应服务。日志可能含文件名；反馈前请移除个人路径、账号、聊天信息和凭据。

欢迎提交问题和改进建议。涉及清理范围、系统操作和聊天数据的修改，请同时说明边界与验证方式。
